# Ledger — Vue Admin Workspace

**[Open the live demo](https://emperialcode.github.io/vue-admin-workspace/)**

A responsive, interactive **Vue 3 + TypeScript** portfolio demonstration of a SaaS admin dashboard. Uses Vite, Tailwind CSS v4, and Lucide icons.

> **Demo only:** All invoice/customer data is fictional. No real payment provider, customer data, private repository, or backend is connected.

## Features

- Reactive KPI summaries and searchable invoice table
- Status filtering and amount/date sorting
- Form validation and locally created invoice rows
- CSV export with escaped values
- Responsive interface, mobile-friendly table, and empty states
- Unit tests for formatting and validation helpers

## Getting started

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
npm run test
npm run build
```

## Limitations

This is a frontend-only demonstration. Changes exist in browser memory and reset on reload. No authentication, backend persistence, actual invoicing, or payment integration.
